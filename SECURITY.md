# Security

Please report security issues privately to **kalmwerk@gmail.com** rather than in a public issue. Include the version, the browser and a minimal page that shows the problem. You'll get a reply within a few working days.

Fixes go into the latest minor version. The banner renders texts and service names you configure with HTML escaping and only links `https://` URLs or site paths; if you find a way around that, or a way to make the banner grant consent the visitor didn't give, that counts as a security issue.
